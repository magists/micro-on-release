# Micro:ON 업데이트 배포소

**Micro:ON — 지능형 과학실 ON 브릿지**의 자동 업데이트용 저장소입니다.
micro:bit에 연결한 센서 값을 읽어 지능형 과학실 ON으로 보내는 윈도우 프로그램입니다.

## 여기 있는 것

| 파일 | 용도 |
|---|---|
| `version.json` | 프로그램이 새 버전을 확인할 때 읽는 파일 |
| Releases의 `Micro-ON-Update-*.exe` | 업데이트용 설치 파일 |

## 처음 쓰시는 분께

**여기 있는 파일은 이미 쓰고 계신 분의 업데이트용입니다.**

Releases의 설치 파일로 처음 설치하면 프로그램은 열리지만
*"인증키가 설정되어 있지 않습니다"* 가 뜨고 데이터를 보낼 수 없습니다.
**인증키가 채워진 설치 파일은 따로 받으셔야 합니다.** 관리자에게 문의해 주세요.

## 업데이트 방법

**따로 하실 일이 없습니다.** 프로그램을 켜면 새 버전이 있는지 알아서 확인하고,
있으면 알림 창이 뜹니다. [지금 업데이트]를 누르면 받아서 설치하고 다시 켜집니다.

- **모둠 ID와 인증키 등 설정은 그대로 유지됩니다**
- 수집(전송) 중에는 업데이트할 수 없습니다 — [수집 중지]를 먼저 눌러 주세요
- [나중에]를 누르면 그 버전은 다시 묻지 않습니다 (더 새 버전이 나오면 다시 알려 드립니다)

## 설치할 때 경고가 뜬다면

*"Windows의 PC 보호"* 창이 뜰 수 있습니다. 코드 서명 인증서가 없어서 그렇습니다.

**[추가 정보] → [실행]** 을 누르시면 됩니다.

## 문제가 생기면

업데이트가 실패해도 쓰던 프로그램은 그대로 쓸 수 있습니다.
혹시 프로그램이 열리지 않게 되면, **처음 받으셨던 설치 파일로 다시 설치**하시면 됩니다.
